CellScope

Advanced Microscopy Image Analysis

A powerful tool for counting and analyzing microscopy objects with multiple thresholding methods and comprehensive morphological quantification capabilities. Designed for researchers, scientists, and medical professionals who need accurate and efficient cell analysis.

Get Started View on GitHub

Key Features

🔬

Multiple Thresholding Methods

Support for various thresholding algorithms including Otsu, adaptive, and manual thresholding for precise object detection.

📊

Morphological Quantification

Comprehensive analysis of cell morphology including area, perimeter, circularity, and other essential metrics.

🎯

Accurate Object Counting

Automated counting of cells and other microscopy objects with high accuracy and reliability.

📈

Data Export

Export analysis results in various formats (CSV, Excel) for further statistical analysis and reporting.

⚡

Fast Processing

Optimized algorithms for quick processing of large microscopy image datasets.

🖼️

Image Preprocessing

Built-in tools for image enhancement, noise reduction, and contrast adjustment.

Installation

Prerequisites

Before installing CellScope, ensure you have the following:

  • Python 3.7 or higher
  • pip package manager
  • OpenCV dependencies

Installation via pip

pip install cellscope

Installation from source

git clone https://github.com/toochii2/Cellscope.git
cd Cellscope
pip install -r requirements.txt
python setup.py install

Verify Installation

python -c "import cellscope; print(cellscope.__version__)"

Usage Guide

1. Basic Usage

Start analyzing your microscopy images with just a few lines of code:

from cellscope import Analyzer

# Initialize the analyzer
analyzer = Analyzer()

# Load your image
image = analyzer.load_image('path/to/your/image.tif')

# Perform analysis
results = analyzer.analyze(image, method='otsu')

# View results
print(results.summary())

2. Advanced Analysis

Configure thresholding methods and morphological parameters:

from cellscope import Analyzer, ThresholdMethod

analyzer = Analyzer(
threshold_method=ThresholdMethod.ADAPTIVE,
min_object_size=50,
max_object_size=5000
)

# Batch processing
results = analyzer.batch_analyze('path/to/images/', export=True)

3. Visualization

Generate visual outputs with detected objects highlighted:

# Visualize detected objects
analyzer.visualize(results, show_labels=True)

# Save annotated image
analyzer.save_visualization('output.png')
📸

Example: Microscopy image with detected cells highlighted

4. Export Results

Export your analysis results for further processing:

# Export to CSV
results.to_csv('analysis_results.csv')

# Export to Excel
results.to_excel('analysis_results.xlsx')

Contribution Guidelines

We welcome contributions from the community! Whether you're fixing bugs, adding new features, or improving documentation, your help is appreciated.

1. Fork the Repository

Start by forking the CellScope repository on GitHub.

git clone https://github.com/your-username/Cellscope.git

2. Create a Branch

Create a new branch for your feature or bug fix.

git checkout -b feature/your-feature-name

3. Make Your Changes

Write clean, well-documented code following our coding standards:

  • Follow PEP 8 style guidelines
  • Add docstrings to all functions and classes
  • Include unit tests for new features
  • Update documentation as needed

4. Submit a Pull Request

Push your changes and create a pull request with a clear description.

git push origin feature/your-feature-name
